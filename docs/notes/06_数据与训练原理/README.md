# 从数据矩阵理解本次 π0.5 训练

这组笔记对应**本仓库、本次 RealMan 数据、本机安装的 LeRobot 0.4.3**，不是所有 VLA 的统一实现。只读核对了数据和源码，没有修改正在运行的训练。

按顺序阅读：

1. [01_LeRobot数据与样本矩阵.md](01_LeRobot数据与样本矩阵.md)：磁盘文件、episode、逐帧表、一个训练样本和 batch。
2. [02_pi05训练与推理矩阵.md](02_pi05训练与推理矩阵.md)：图像/状态/文字怎样进入模型，flow matching 学什么，训练和推理的区别。
3. [03_怎么看效果与训练耗时.md](03_怎么看效果与训练耗时.md)：loss 能说明什么，为什么约两天，学习率/步数/batch 的区别。

先记住这张表：

| 量 | 本次设置 | 含义 |
|---|---:|---|
| 一帧状态 | 7 | 6个关节角度＋夹爪开合 |
| 一帧动作 | 7 | 下一帧实际关节位置与夹爪状态，作为监督目标 |
| 一个训练样本 | 当前两张图＋状态＋任务文字＋`50×7`动作 | 从某个时刻出发，学习一段未来动作 |
| 每卡 batch | 2 | 每卡一次处理2个样本 |
| 全局 batch | 8 | 4卡合起来一次更新用8个样本 |
| 模型内部动作 | `B×50×32` | 7维补零到32维以匹配基座；loss只算前7维 |
| 训练时直接预测 | `B×50×32`速度场 | 数学上的动作空间流场，不是关节角速度 |
| 推理动作块 | `B×50×7` | 积分完成后裁回实际7维，再反归一化 |
| 单次下发 | 通常`7` | `select_action`每次返回一个动作；另有batch维 |

三个“步”要分开：**54075个优化器更新步、每块50个未来动作时刻、推理10个流场积分步**，它们不是同一个轴。

源码入口是 [train.sh](../../../scripts/train.sh) → [prepare_pi05.py](../../../scripts/prepare_pi05.py) → [train_pi05_fsdp.py](../../../scripts/train_pi05_fsdp.py)。模型逻辑在本机`.venv/lib/python3.11/site-packages/lerobot/policies/pi05/`，可对照[官方v0.4.3源码](https://github.com/huggingface/lerobot/blob/v0.4.3/src/lerobot/policies/pi05/modeling_pi05.py)。本笔记的具体形状和行为以本机安装源码与运行配置为准。
